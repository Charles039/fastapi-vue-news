FastAPI + Vue 新闻系统 Windows 演示版
=======================================

使用方法
1. 请先完整解压 ZIP，不能直接在压缩包预览窗口中运行。
2. 双击 FastApiVueNews.exe。
3. Windows 如果显示“未知发布者”，请选择“更多信息 → 仍要运行”。
4. 程序会自动选择可用端口，并打开默认浏览器。
5. 关闭命令行窗口或按 Ctrl+C 即可停止服务。

数据说明
- news.db 位于 EXE 旁边，包含八个分类、演示新闻和演示管理员。
- 注册账号、收藏、历史、通知和管理修改都会写入 news.db。
- 删除程序文件夹或覆盖 news.db 会丢失演示期间产生的数据。
- 请将整个文件夹放在有写入权限的位置，不建议放入 Program Files。

其他说明
- 新闻封面图片使用互联网 URL，完整展示需要网络连接。
- 服务只监听本机 127.0.0.1，不会作为公网服务器运行。
- 本程序用于项目展示，请勿用于保存真实敏感信息。
